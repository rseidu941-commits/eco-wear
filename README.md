

# Eco Wear

**Sustainable Fashion for a Better Tomorrow**

## Description

Eco Wear is a sustainable fashion e-commerce platform built with React. It showcases ethically made clothing and accessories crafted from eco-friendly materials. The platform provides a seamless shopping experience with product browsing, category filtering, search, and cart management — all wrapped in a clean, responsive design.



## Built With

| Technology | Purpose |
|---|---|
| **React 19** | Frontend UI framework |
| **React Router v7** | Client-side routing |
| **Vite 8** | Build tool and dev server |
| **Sass (SCSS)** | Styling and theming |
| **Figma** | UI/UX design |
| **Stitch** | Prototyping |
| **Jira** | Project management and task tracking |
| **GitHub** | Version control and collaboration |

---

## Features

- **Product Catalog** — Browse dresses and jewelry with category filtering
- **Live Search** — Filter products by name in real time
- **Shopping Cart** — Add, remove, and adjust item quantities with automatic order summary
- **Product Details** — View individual product information with quantity selector
- **Create & Edit Products** — Admin forms to add or update product listings
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices
- **Sustainability Focus** — Messaging around eco-friendly materials, ethical production, and sustainable packaging
